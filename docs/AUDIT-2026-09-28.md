### I02 — Narxli shtrix-kodda miqdor aniqligi

- **Chiqarish:** server avval (eski kassalar ham o'tadi), keyin POS 1.18.7. Tartib muhim emas — ikkalasi ham orqaga mos.
- **Qaytish:** server — oldingi deploy'ga rollback (migratsiya yo'q). POS — 1.18.6 relizi saqlanadi.
